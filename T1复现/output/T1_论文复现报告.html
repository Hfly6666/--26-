01论文与经济管理问题

原文：Qi, M., Shi, Y., Qi, Y., Ma, C., Yuan, R., Wu, D., & Shen, Z.-J. (2023). A Practical End-to-End Inventory Management Model with Deep Learning. Management Science, 69(2), 759–773. DOI: 10.1287/mnsc.2022.4564。在线发表日期为2022年12月13日。报告使用用户提供的最终刊发PDF。

电商平台面对大量需求稀疏、波动且补货提前期不确定的商品，必须平衡持有库存的资金与仓储成本，以及缺货造成的服务损失。传统“先预测、后优化”（PTO）先估计需求和提前期，再代入库存公式。预测误差最小与库存成本最小之间可能不一致。

论文提出从业务特征直接输出补货量的E2E模型：先用历史上已经发生的需求与提前期求出事后最优动作，作为监督学习标签，再训练神经网络逼近该动作。它以决策质量为最终目标，并保留需求预测和提前期预测两个辅助任务。

论文离线实验覆盖24,333个SKU；现场实验在京东12个配送中心开展，涉及61,430张补货订单和9,308个SKU，处理组与对照组各6,097个SKU–配送中心对。现场处理对象由业务管理者选择，具有选择性，不能按随机对照试验解释（原文§4–§5，印刷页765–769）。

02理论、监督标签与网络结构

2.1 有限期库存决策

设需求为dt，期末净库存为It，负净库存代表延期交付需求。期末成本为h·max(It,0)+b·max(−It,0)。固定盘点日期、随机提前期决定订单到货时刻。理论推导假设完全延期交付，且各批订单的到货顺序不发生交叉。

min E[Σₜ (h·Iₜ⁺ + b·(−Iₜ)⁺)]，qₘ ≥ 0
α = b / (b+h)

2.2 用已实现路径构造最优动作标签

对于两个相邻到货时刻之间的n天，令cj为从本次到货日累计到第j天的需求，I为本次到货前净库存。非负需求使c单调。事后成本关于到货后库存水平是分段线性凸函数；平衡持有与缺货的边际成本，可选取累计需求的α分位点。

cⱼ = Σₖ₌₀ʲ dₖ，j=0,…,n−1
j* = min(n−1, floor(αn))
q* = max(0, cⱼ* − I)

αn为整数时可能存在一段等价最优解；上式给出其中一个。此标签使用未来已经实现的路径，属于事后监督信息，不能视为上线时已知信息。测试期的OPT同样只是事后参考，不是可部署算法，也不代表其他算法相对真实随机动态规划最优策略的差距。

本次对5组α（0.1、0.5、0.88、0.9、0.95），共1000个随机单周期实例，枚举整数补货量验证标签成本等于最小成本；另对100个两到货周期实例枚举两次动作。全部通过，最大数值成本差3.55e-15。这些有限规模检验是公式实现校验，不能替代论文的数学证明。

2.3 多任务E2E网络与训练配置

L(θ) = (1/N) Σᵢ [ Lorder(Out1ᵢ, q*ᵢ) + λ₁ Ldemand(Out2ᵢ, DF*ᵢ) + λ₂ Lvlt(Out3ᵢ, VLT*ᵢ) ]

论文式(6)采用订单、需求与提前期三项损失；λ₁、λ₂为较小正权重，所提供正文没有给出其具体数值。表B.1给出学习率0.001、learning rate decay 10⁻⁴、momentum 0.85、batch size 64、高斯初始化均值0/标准差0.01。这里保留作者对decay的命名，缺少训练源程序时不推断其具体实现。

原实验用最早30天样本中的80%训练、20%验证，后30天测试；论文附录的全部训练规模为19,466个SKU，硬件为Tesla P40。公开CSV中没有相应完整132维特征与可还原的训练时间切分。本次只解释训练流程，不把现成预测列用于训练后宣称重训成功。

04逐步复现的实际执行过程

  1. 读取材料：提取PDF正文与附录，解压原始包，检查CSV维数、ID、库存向量和笔记本代码。
  2. 执行离线评价：运行作者离线笔记本的数值单元格1–15，仅替换输入文件路径；跳过导入单元格0和LaTeX展示单元格16。将3000行聚合为2607个SKU，逐方法计算库存轨迹与成本。
  3. 独立交叉核对：另写库存路径计算器，对全部SKU与全部7种方法逐项比较，成本最大绝对差为0；再与笔记本保存的6位小数汇总比较。
  4. 统计与口径审计：执行2000次SKU层面配对bootstrap；检查负订单、提前期计费窗口、Normal基准公式；每个敏感性分支独立保留。
  5. 现场结果重算：从四份原始库存CSV重新计算持有、缺货、总成本、库存天数和缺货比例；重算等方差t检验、Welch检验、无常数项OLS、含常数项OLS、HC3和四组均值DiD。
  6. 核对原代码执行状态：顺序运行现场笔记本的28个非回归数值单元格，保存实际日志；回归用NumPy最小二乘独立实现，避免旧依赖版本阻碍重跑。
  7. 复现匹配与理论检验：用SciPy求解L2逻辑回归，并区分原始协变量近邻和一维倾向得分近邻；验证事后补货标签。
  8. 导出：保存逐SKU/逐单位CSV、统计JSON、数据指纹、独立PNG图表和本HTML；打包源材料、脚本与结果供复运行。

执行脚本不需要GPU；这源于本次重算公开预测输出和库存轨迹，并不意味着原始E2E网络无需GPU训练。

6.1 负订单会影响方法排序

原笔记本用“预测列值减某个历史库存”再取整生成动作，未执行max(0,q)。在3000次RNN动作中，有525次为负（17.5%）；原材料将预测列描述为补货输出，但实际评价代码把它们按目标库存量解释。本次忠实复跑该代码，同时单独检查非负动作约束。

只将负动作截为0时，RNN成本为2671.75，GBM为2564.07，BM2为2641.03；最低非事后成本变为GBM。这说明原排序依赖评价实现。该分支仍沿用其他原逻辑，不能称为完整业务修正版。

6.2 提前期与欠交状态

原模拟中，第一次到货前的库存变化不计入最终评分向量；后续记录在到货前的循环日直接跳过。每种方法均有2068个这样的后续循环日被跳过；有11次历史索引越界回退。到货日更新包含max(上一日库存,0)，会清除先前负净库存，不能直接视为论文理论中的完全延期交付递推。

“只补计首次到货前窗口”保留其余状态更新，只把已生成的库存路径纳入评分，因此各方法成本都增加约3485.00；它没有补齐后续被跳过的日，也没有修复延期交付逻辑。该相同增量并不构成新策略效果。

6.3 PTO基准的实现差异

论文式(7)：S = μᴅ(R+μᴸ) + zα·√[(R+μᴸ)σᴅ² + μᴅ²σᴸ²]

笔记本Normal基准使用z=1.64，而α=0.9对应z=1.28155；还把提前期不确定项写成σᴅ²·σᴸ。按论文式(7)改写两处、目标库存向下取整，沿用原模拟器，成本变为3925.87，原值为3961.69。这只是公式一致性分支。

原笔记本的BM1/BM2以sf_rnn列表均值参与计算，而正文描述了多分位需求预测与最优分位选择。公开包没有完整预测结构、训练代码和选择过程，不能将这两个公开计算列当作完整恢复了论文的全部PTO建模流程。

08匹配机制与平衡性复现

使用500个处理样本与55,333个候选对照，以日均需求和提前期拟合带L2惩罚的逻辑回归（C=1、截距不惩罚）。SciPy直接最小化对数损失加惩罚，得到参数（截距、需求、提前期）=（-3.861126，-0.002378，-0.087331），梯度无穷范数1.06e-09，求解成功。

原代码虽计算倾向得分，但最近邻检索使用原始需求和提前期列，而非得分列。源代码还包括组别指示列；对所有处理—候选组合，该列差均为1，对欧氏近邻排序只增加常数，等价于未标准化的两项协变量匹配。故原方法在实现上属于协变量近邻匹配。为明确差别，本报告另算真正的一维倾向得分匹配作为补充，不替换原结果。

12研究结论、管理含义与限制

第一，决策导向学习具有可检验的管理价值。在作者公开评价口径下，E2E-RNN实现了比多个PTO计算列更低的平均库存成本，且配对SKU bootstrap支持平均差异。但优势集中程度不均，部署时应比较商品级损失，而非只看全平台均值。

第二，策略优势与评价器必须一起审计。负订单、欠交状态清除和提前期窗口会改变库存成本甚至方法排序。业务落地需要统一订单非负约束、日历、到货事件和欠交记账规则，再在相同事件模拟器中重新比较算法。

第三，现场样本提供相关性证据，因果效应仍需更完整设计。成本差、回归和DiD方向大体有利于E2E，但管理者选择处理对象、窗口不等长、脱敏映射不明和缺乏多期趋势限制了识别。统计显著不能单独解决这些问题。

本次已完成：公开数据评价复跑、历史结果核对、独立路径交叉检查、统计规格比较、匹配机制重建、理论公式数值验证、可离线HTML与代码数据导出。尚不能复现：原网络训练与收敛、完整分位预测与参数选择、24333个SKU全量实验、全量现场身份匹配、在线业务决策和原文全部网络超参数消融。补齐这些部分需要作者原训练数据、特征处理、损失权重、训练代码和全量面板，公开示例文件不足以支持。

因此，合适的作业结论是：成功重算了公开包可验证的主要评价结果，并发现数项影响解释与排序的实现差异；不能宣称完成原论文所有实验或证明E2E在任何业务口径下都最优。
